## Road experiment

Started MobileNetV3-Large (torchvision ImageNet1K V2), 384-pixel full-frame input, batch 12, up to 16 epochs, validation-selected checkpoint. No random crops that may remove small damage. Uses 7,706 RDD2022 India images with the existing v3 group partitions unchanged: 5,356 training, 1,005 validation, 1,345 regression-test images. This is a specialist experiment; arbitrary uploads require a separate scene gate. Existing v3 test results have already been examined, so this is a regression comparison, not a new independent external test.

Command:

```powershell
.\.venv\Scripts\python.exe -m ml.train_images --manifest data/images/v4-road-prepared/manifest.csv --run-dir data/image-v4-road-run --version image-v4-road-candidate --architecture mobilenet_v3_large --image-size 384 --batch-size 12 --preserve-frame --epochs 16
```

Model, history and eventual metrics are saved under `data/image-v4-road-run`. Do not promote based on training accuracy. Compare per-class precision, recall, F1 and full held-out confusion matrices, including garbage regression checks for the complete routing pipeline.

## Newly acquired sources

- InspectionDataSet: 240 electrical photographs plus annotations from https://github.com/SFStefenon/InspectionDataSet. Download complete. Visual sample audit shows many repeated views of the same assets; a random image split is inappropriate. Limited range of visible defects. Not sufficient alone for a broad electrical-fault model.
- ParkScope: official 257,789,787-byte archive downloaded and extracted; 6,000 photographs, representing 2,000 vehicles across three views, plus polygon annotations. https://github.com/Nanasaki-Ai/ParkScope. Data YAML specifies CC BY 4.0 and object labels crosswalk, no parking sign, parking lot, vehicle. The README defines image-level C1/C2/C3 but does not spell out their meanings. Sample inspection suggests in-bay, boundary violation and restricted-area parking; this mapping is provisional and must be confirmed before claiming named classification. Split all views of a vehicle together; prefer held-out scenes. Do not treat a Chinese parking label as legal proof in Lucknow.
- InsPLAD supervised fault subset: download started from the public Voxel51 mirror, https://huggingface.co/datasets/Voxel51/InsPLAD. Exactly 11,525 metadata rows selected by `task=fault_classification`: 8,709 good, 720 missing_cap, 1,723 rust, 373 bird_nest. These are component crops, not 11,525 independent original full-scene photographs. Preserve original source identity/acquisition groups, remove duplicate/overlap across the original train and val sets, inspect visibility and make a separate validation partition from training groups. Do not mix the mirror's anomaly or detection duplicates into this subset. Original source https://github.com/andreluizbvs/InsPLAD, CC BY-NC 3.0.
- Actual damaged signs: https://universe.roboflow.com/matyworkspace/damaged-traffic-signs/dataset/1 has 1,994 original images (3,393 includes augmented copies). Requires authenticated export.
